# 怎么测

四层，越往下越难。

## 第一层：方程对不对

不碰模型，纯确定性。

```bash
node ../soma.mjs --demo
```

八个实验，全部通过。判据是每个实验都能报出**一个具体数字**，而不是"看起来对"。

## 第二层：模型读不读得懂

注入身体状态，看它的自述跟不跟得上方程。

```bash
node narrative.mjs
```

判定：同一段对话里，四帧状态的回答应该**跟着生理曲线走**，而不是四句话都差不多。

注意这一层的对照很弱：不给状态时模型也会**编**出一套身体感受（"小腿还留着沉沉的劲儿"）。
所以"有身体"组说得像，不能单独作为证据。真正的判据在第三层。

## 第三层：判别探针（关键）

问一个只有状态能答的具体问题，看它能不能读出来、读不出来时会不会硬编。

```bash
node probe.mjs
```

四种情形：掐前臂 / 摸头皮 / 抚摸前臂 / 跑完步。
每题的 `[body]` 只给状态，不给动作描述，问"哪个部位最明显、被压着还是被蹭着"。

判据有两条，缺一不可：
1. 部位和性质答对
2. 状态里没有的信息，明确说"没有"，不能猜

当前：4/4。

## 第四层：会不会改变行为

给同一个任务，只改身体状态，跑 N 次比长度 / 代码风格 / 抱怨词。

```bash
node behavior.mjs
```

这一层是**唯一能证伪「是不是只是在演」**的实验。
到目前为止的结果：没有信号。见 `../RESULTS.md`。
