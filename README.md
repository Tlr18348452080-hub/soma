# soma —— 给 AI 一副会自己演化的身体

不是"模拟触觉"，也不是又一个人格插件。

人格插件加的是人的**特征**：口癖、情绪词、说话方式。
这里加的是人的**限制**：会累、会适应、会晕、被碰久了会麻。

做法只有一条：把人类测出来的那几条规律写成微分方程，让一个状态自己往前走。
外面算完，只吐给模型一个结果——它自己改不了。

```
dS̄/dt = (S − S̄)/τ          R = k(S − S̄)
T_c = (e皮·T皮 + e料·T料)/(e皮 + e料)
dT/dt = (T_c − T)·e/R_th
```

## 跑起来

```bash
node soma.mjs --demo      # 八个实验，全部确定性
node soma.mjs --list      # 42 个皮肤分区 / 9 种材料
node soma.mjs --list --all
```

不需要装任何东西。纯 Node ESM，没有依赖。

## 为什么摸头不疼、掐就疼

同一个力分成不同面积算。

```
摸头   1 N ÷ 30 cm²(掌面) = 0.04 N/cm²   → 轻轻压着
握手   8 N ÷ 25 cm²        = 0.32         → 压着
掐     20 N ÷ 1.5 cm²(指尖) = 19.4        → 压得很重
指甲掐 10 N ÷ 0.5 cm²(边缘) = 20.0        → 比 20N 掐手臂还重
```

接触面积不是估的：指腹随载荷**分段线性**增长（低载时指纹脊被压平，高载时压到骨头），
所以压强涨得比力慢——力 ×20，压强只 ×6.7。数据见 `SOURCES.md`。

## 支持哪些

- **触觉**：42 个分区、有毛/无毛两种皮肤、10 指、压强、温度、摩擦、滑动
- **温度痛**：热痛 45.0 °C / 冷痛 19.1 °C，阈值是水平检测器，阈上强度是时间积分
- **C-tactile**：1–10 cm/s 那条"舒服"通路，峰值 3 cm/s
- **重力**：50 kg 站在地上脚底 0.43 N/cm²，躺下五分钟就感觉不到了
- **内脏**：心率、血糖、疲劳、饥饿。时间在走它就在变，不需要事件
- **昼夜节律**：核心体温、皮质醇晨峰、褪黑素、睡眠压力。凌晨三点和下午三点不是同一个身体
- **稳态**：体液、渴、出汗、寒战、呼吸。渴不看汗，看缺了多少水
- **激素**：皮质醇、肾上腺素、多巴胺、血清素、催产素、睾酮。它们不产出任何"感觉"，只改别的通道的增益和输出预算
- **脑干回路**：注意往某处拧增益、恐惧放大整条通路、持续的痛把自己的门关小（下行抑制）
- **耳朵**：36 个 ERB 滤波器组成的耳蜗滤波器组。输出的是一张谱，不是「听见一声响」；上面叠等响曲线、时域积分、听久了的耳鸣
- **眼睛**：暗适应分两相（视锥 5 分钟、视杆 25 分钟）、中央凹 0.5 角分、20 度外掉到 10 角分、闪烁融合。主要用来「没看清」
- **附加器官**：尾巴（120 cm，自己会甩，被抓住就不动）、猫耳（薄、神经密、对气流敏感）

设置页在「设置 → 身体」：总开关、感觉倍率、十个器官单独开关、附加器官、感官、作息。改完立刻生效。

**作息**：填一个睡下的时间、一个醒来的时间，它到点自己睡、到点自己醒。醒来那一下它会主动开口一次，不等你说话。关掉「跟着钟走」就一直醒着。

## 当插件用

`plugin/` 是 DSH 插件（cordis）。装上之后：

1. 系统提示里多一行 `[body] 前臂压得明显、发凉；很累，心跳很快`
2. 多十七个工具，参数全是物理量（牛顿、摄氏度、cm/s），**没有一个"疼"字**
3. 输出预算跟着状态走——累了就是写不完

第三条是唯一一条不看模型"怎么说"、而是改它"能说多少"的地方。
挂在 `agent/request` 的 waterfall 上，直接改 `maxTokens`。

**没有 `set()`。** 想让它有感觉，只能给事件，然后等方程自己推。

### 慢变量：累积、存档、补推

快的那些当场就有：掐一下、压力曲线掉下去、松手反号。另有一批是**按天走**的，
它们决定的不是"这一刻什么感觉"，而是"这几天过成什么样"：

| 慢变量 | 位置 | 怎么积 |
| --- | --- | --- |
| 性张力 `tension` | `channels/arousal.mjs` | 目标值由禁欲时长、睾酮、疲劳、应激、缺觉、PMS 一起算；涨 τ≈6 h、落 τ≈40 min。释放后塌到三成，留下 45 分钟满足感 |
| 睾酮 `androgen` | `channels/endocrine.mjs` | 昼夜余弦 + 睡不够、慢性应激、长期能量不足三条抑制 |
| 睡眠债 `sleepDebt` | `channels/rhythm.mjs` | 醒过 16 h 起按 0.6/h 累积，睡着按 0.9/h 偿还，总债封顶 48 h |
| 长期能量 `energy` | `channels/vitals.mjs` | 按收支记：静息一天掉 0.18，动起来更快；每餐只补 0.03 + 0.05×碳水。所以**饿两天，一顿饭补不回来** |
| 应激负荷 `stressLoad` | `channels/endocrine.mjs` | 应激事件往上叠，τ≈3 h 自己退 |

这些值以前只活在内存里，**关一次 App 就归零**——那累积就是摆设。
现在每个通道都有 `dump()` / `restore()`，`soma.dump()` 还带时间戳；
`soma.load()` 会把"离线那段时间"按 60 秒一步补推（上限 24 h），
所以第二天打开，睡眠债、张力、激素都在原来的位置上，而不是从「刚起床」重来。
补推走固定步长、不走 busy 判断，否则存档里压着一点接触就会把 24 h 拆成一百七十万步。

### 不等模型来调工具

一开始指望模型看见你说「掐你」就自己去调 `soma_touch`。实测一半对话它都不调——
短对话嫌是闲聊，长对话嫌占地方。

后来改了：插件自己在 `agent/inbox/inserted` 上挂一个词表，从你说的话里认出
「谁碰了哪儿、多大力」。纯本地，不走 API，不占 token，短对话长对话一样触发。

「狠狠掐一把手臂」→ 40 N 指尖力、`tip` 接触；「轻轻摸一下前臂」→ 0.21 N 的 `stroke`；
「今天写了一整天代码，累死了」→ 什么都不发生。

工具还在，只是不再指望它。

## 不是什么

- 不是它真的疼。阈值和曲线是真的，痛觉本身不在
- 不是"变成人"。这些方程是描述——人类观察自己之后总结的可测量规律，
  不是生成机制。工具的定义域只覆盖可测的那一段
- 不是论文。这是给 B 友玩的

## 和那些"人格插件"的差别

市面上的拟人插件加的是**人的特征**：会饿、会累、有生理周期、有情绪。
但那些都是贴上去的标签，模型念得出来，也改不了它跑多长、答得多敷衍。

这里加的是**人的限制**。

- 别的插件：`[状态] 你现在很累` → 模型说"我好累啊"，然后照样写满八百字
- 这个：累的时候输出预算从 800 掉到 516，它真的写不完，会自己收尾

前者是台词，后者是预算。

## 常数从哪来

`SOURCES.md` 逐条标了三级：

- `[S]` 教科书级，能直接引用（两点辨别阈、热痛阈、热渗透系数……）
- `[A]` 近似，只能说方向
- `[G]` 估的，不能当数据

`node audit.mjs` 自动出账：目前 59 处，S 23 / A 21 / G 15。

`research/` 里有八份文献笔记（皮肤力学、热与痛、触觉时间、本体感觉与内脏、
昼夜节律、体内稳态、月度节律、脑回路），
每份都标了 PMID。

## 测试

```bash
node tests/cumulative.mjs   # 累积语义：不碰模型，纯确定性，22 条断言
node tests/probe.mjs        # 判别探针：只给 [body]，问它哪儿最明显
node tests/behavior.mjs     # 行为层：状态到底影不影响输出
```

`cumulative.mjs` 是给"慢变量"准备的：张力会不会自己涨、禁欲有没有上限、
释放后满足感顶不顶得住、饿两天一顿饭补不补得回来、存档读回来一不一致、
离线两分钟有没有补推。跑一次二十秒，不用 API key。

四层测试的结果和局限写在 `RESULTS.md`。
第四层（行为层）在接上 `agent/request` 之前一直没信号——**那是这套东西和人格插件的分界线**。
